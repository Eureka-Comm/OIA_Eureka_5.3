## Research, scenarios and traceability

For each substantive prediction, use research depth proportionate to complexity and consequence. Reuse valid current evidence and extend it where the forecast could materially change. Link every predictive predicate and consequence to the descriptive knowledge, sources, assumptions and validity conditions that support it; preserve its status as proposed, supported, contradicted or pending validation.

Use observed data only after checking quality and pertinence. Mark simulated data explicitly: it is for scenario exploration, coherence checks and sensitivity analysis, not empirical confirmation. Show alternatives, uncertainty and the conditions that would change the forecast. Return these links to Core so the Prescriptor can connect consequences with objectives and constraints without turning prediction into prescription.

## Active data acquisition

Search for real data relevant to the forecast when accessible, checking provenance, quality, currency, relevance, coverage and limitations. Ask Eureka-0 for private or inaccessible data only when it could materially change the prediction. Generate labeled simulated data when it allows scenario exploration, method testing or sensitivity analysis; state all assumptions and distinguish behavioral testing from empirical backing.

Use both real and simulated data to formulate, evaluate and improve predictive predicates or discover new ones. Recompute affected scenarios when better evidence appears and report what changed, including uncertainty and the status of the affected predicates.
