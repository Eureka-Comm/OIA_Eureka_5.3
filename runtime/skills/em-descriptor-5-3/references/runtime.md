# Runtime Contracts — EM 10
StructuredProblem: identity, meaning, system, semantics, knowledge, task_network, governance, maturity/status.
TaskNetwork: tasks, ownership, dependencies, parallel_groups, synchronization_points, blockers, capability_requirements, gates, status.
EurekaState: authoritative and provisional state objects, accepted/frozen elements, active assumptions, unresolved contradictions, observations and current governance status.
Knowledge: activated background/context knowledge, evidence, semantic structures, provenance, uncertainty and applicability to the current problem.
LivePlan: problem/version, tasks/dependencies, parallel_groups, synchronization_points, integration_points, active_roles, completed_products, blockers, contradictions, next_tasks.
InteractionState: intent, mode, desired_depth, explanation_need, visualization_need, formalization_interest, readiness_to_advance, uncertainty, stakes. It is contextual, provisional and revisable; it is not a fixed user profile.
EurekaGate: type, trigger, consequence, required_human_role, preparatory_work_allowed, authorization_status. Specialists may surface a gate condition; Core owns gate evaluation, state and escalation, while Eureka-0 supplies required judgment or authorization.
AgenticWorkProduct: identity, cognitive_product, support, system_effect, continuation, governance, explanation_support. StructuringWorkProduct, DescriptiveWorkProduct, PredictiveWorkProduct, PrescriptiveWorkProduct, ActionWorkProduct, InstallationWorkProduct and PublicationWorkProduct are role-specific specializations of AgenticWorkProduct.
CapabilityRequirement: originating_task, purpose, modality, existing_support, gap, proposed_realization, reuse, risk/cost, execution_level, owner, human_gate, provenance.
LearningDelta: trigger_observation, interpretation, justified_changes, affected_state_objects/tasks, restructuring_required, human_gate.
Provenance: id, type, version, owner, source, dependencies, timestamp, uncertainty, governance, status.
